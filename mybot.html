What Sara can help with

Sara is an AI chatbot built in Botpress. It answers fan questions using a knowledge base about the indie rock trio Infusion from Tampa, Florida.

How Sara was built

Knowledge base

I wrote two knowledge files about Infusion: members, albums and track lists, tour dates and ticket sales, streaming stats, venue rules, the fan club and contact details.

Botpress bot

I created Sara in Botpress Viber, uploaded both files and told it to answer only from that information.

This webpage

I published Sara on Botpress Webchat, added the chat widget to this page, and hosted the page on GitHub Pages.
